# 极简 AI 速报设计

## 目标

把现有展开式日报改为适合手机和邮件快速浏览的极简速报。读者应能在一个屏幕内理解当天主题，并通过可点击标题直接打开中文原文。

## 最终格式

```markdown
# 每日 AI 速报 · 2026-08-04

📮 今日 AI 猛料：一句话概括当天最重要的整体趋势。

1. [精炼中文标题](中文正文链接)
2. [精炼中文标题](中文正文链接)
3. [精炼中文标题](中文正文链接)
```

## 内容规则

- 报告保留日期、一句总概括和编号资讯列表。
- 每期最多 10 条；高质量候选不足时按实际数量发布，不凑数。
- 每条仅显示一行精炼中文标题，标题本身直接链接到已验证的中文正文。
- 优先使用模型编辑后的标题；规则降级时使用中文来源原标题。
- 标题去除多余标点和首尾空白，最长 35 个可见字符；过长时截断并添加省略号。
- 不显示单条摘要、来源、时间、分类或“为什么值得看”。
- 不显示趋势列表、运行状态、模型模式、校验统计、警告和来源错误。
- 抓取与校验统计继续写入 Actions 标准日志，不改变抓取、筛选、中文链接验证和邮件发送流程。

## 空结果与异常

没有合格候选时，仍输出日期和一句“本期没有筛出足够可靠的中文 AI 资讯”，不渲染空编号列表。模型或来源失败继续按现有机制降级，并只在 Actions 日志中显示。

## 共享方式

`reports/latest.md`、日期归档、每日 GitHub Issue 和邮件正文继续读取同一份 Markdown，因此四个入口保持完全一致的极简格式。JSON 产物保留完整结构，便于调试和以后扩展。

## 测试标准

- 报告包含日期、总概括和可点击编号标题。
- 标题超过 35 个可见字符时稳定截断。
- 报告不包含摘要、来源、时间、分类、趋势、运行状态和错误提示。
- 未知模型候选 ID 仍不能注入链接。
- 空候选报告保持简短并可正常生成。
