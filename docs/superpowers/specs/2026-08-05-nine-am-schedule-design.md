# 每天九点发送设计

## 目标

将每日 AI 邮件从北京时间 07:00 调整为每天北京时间 09:00，保留现有手动运行入口和全部生成、存档、邮件发送逻辑。

## 方案

GitHub Actions 的 `schedule.cron` 使用 UTC。北京时间全年为 UTC+8，因此北京时间 09:00 对应 UTC 01:00。工作流 cron 从 `0 23 * * *` 改为 `0 1 * * *`，并同步更新工作流注释与 README。

GitHub 定时任务可能因平台繁忙延迟几分钟；此行为保持不变。手动点击 `Run workflow` 不受影响。

## 验收

- 工作流只保留每天一次的 `0 1 * * *` 定时表达式。
- README 明确显示北京时间 09:00。
- 工作流测试和完整测试套件通过。
